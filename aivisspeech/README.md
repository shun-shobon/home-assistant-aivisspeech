# AivisSpeech Engine

Runs the official AivisSpeech Engine CPU image inside Home Assistant OS or Home Assistant Supervised. Use the existing VOICEVOX TTS integration to add its speakers and styles as a Home Assistant TTS entity.

The engine API is available only through Home Assistant's internal add-on network. Add `.aivmx` models under `/share/aivisspeech/Models` and restart the add-on to load them.
